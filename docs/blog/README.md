# 系列文章（计划）

README 只留亮点和上手路径，长出来的部分写成一组文章放在这里。计划中的篇目，按
"读者拿到手会先问什么"排序：

1. **一个窗口就是一次交易**——为什么任务是 4 KiB 步长、镜像/栈/护栏洞/增长余量怎么
   一起算，以及为什么 `msh` 卡在 16 KiB（`HISTORY.md` §30.3、§33.2.1）。
2. **没有 MMU 的隔离**——PMSAv8、PMP TOR、PMP NAPOT、软件哨兵四种后端，什么能守、
   什么守不住（`.rodata`、着陆区），以及"护栏洞不许被盖住"这条规矩（§31、§34）。
3. **SMP 的四个半 bug**——从"两个核跑同一个 shell"到 `process_console_kick()` 的
   slot 竞态，每一段都附上当时的回显（§28、§35）。
4. **刷完不出字的 120 秒**——时钟树顺序、ROSC、PLL，和你以为的"复位后应该一样"
   （§33.4）。
5. **模拟器的谎言**——RV32EMU-C 与 Go 版、`RunHot` 块缓存、以及"Step 路径正常"
   如何把范围缩到一个漏掉的 `touchCode()`。
6. **PIO 的第一天**——寄存器位域、`in pins` 落在 bit31、以及 `pio exec` 这条探针
   怎么结束三轮错误理论（§32.1、§32.2）。

每篇都会是"现象 → 证据 → 结论"，和 `HISTORY.md` 的写法一致；素材已经在历史记录和
`build/sizeprobe/` 的原始日志里，缺的是把它们串成叙事。
