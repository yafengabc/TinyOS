在带 44 个语料时**起不到 USB 枚举**，已单独立案（#42），本轮按用户要求先用 SMP 完成

### `file1` 在 M33 上与 RP2040/宿主不一致（不是本 issue 的失败）

同一份 `file1.c`：

```text
M33（本卡）：  write("hello",5) 返回 5，read 返回 5 字节，文本 "hello"
RP2040（#38）： 返回 24，read 返回 0 字节，文本行是空的
宿主 rvm：     返回 24，read 返回 0 字节（expect 文件就是这么写的）
```

5 / 5 字节才是 `write(5 字节)` 应有的结果，所以 M33 的 native 路径是对的，**RP2040 与
解释器那条路径才是可疑的**。这是 Thumb-2 与本 issue 无关的独立缺陷，另案追踪。
