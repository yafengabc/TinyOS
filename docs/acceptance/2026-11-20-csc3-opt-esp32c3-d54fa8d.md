notes:
- New Q16.16 folding uses the same `fmul16`/`fdiv16` algorithms as `rirvm`, so folded and runtime values agree bit for bit. Mixed int/float literals are converted to Q16.16 first.
- Copy propagation is straight-line only: after `MOV src, dst`, later reads of `dst` become `src` until either register is redefined, a branch, or a branch target. It never rewrites across control flow.
- `dce` still removes only pure definitions whose vreg has no readers anywhere. `compact` then drops NOPs and remaps `JMP`/`JZ`/fused-branch targets; a target that lands on a NOP maps to the next real instruction.
- Fixed peephole to stop at `JZ` (it previously scanned the fallthrough block and could remove a value used on the branch target path).
