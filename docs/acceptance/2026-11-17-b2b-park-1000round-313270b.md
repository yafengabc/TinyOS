## 执行的命令与结果

两板各刷当前 `main` 镜像，切 BOOTSEL 用 `flash.py --boot-uart COM14`：

```sh
# RV32（Hazard3）
python scripts/rp2350/flash.py --boot-uart COM14 --uf2 build/rp2350rvsmp.uf2 -p COM17 --timeout 90
python scripts/rp2040/heartbeat.py --port COM14 --target rp2350rvsmp   # HEARTBEAT OK 6/6
python dd1000.py COM14 dd1000-rp2350rvsmp-313270b 1000                 # 1000 轮
smpbench                                                               # 1.99x

# ARM（Cortex-M33）
python scripts/rp2350/flash.py --boot-uart COM14 --uf2 build/rp2350smp.uf2 -p COM17 --timeout 90
python scripts/rp2040/heartbeat.py --port COM14 --target rp2350smp     # HEARTBEAT OK 6/6
python dd1000.py COM14 dd1000-rp2350smp-313270b 1000                   # 1000 轮
smpbench                                                               # 2.08x
```

每轮 `dd of=/x bs=512 count=1` + `rm /x`；检测 write error / park timeout /
panic / fault / reboot；末尾 32 KiB `dd of=/y bs=4096 count=8` + 回读校验。
