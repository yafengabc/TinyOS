# 2026-11-20 RP2040 启动期有界 pump 验收（#31）

## 范围

#31 的代码部分已在 `f917fcc` / `670a712` 落地：RP2040 端口与 M33 共用同一形状的
有界 pump，`n = plat_cpu_hz()/3125`（125 MHz → 40 000 次，约 250 ms），
clamp 到 `[4000, 200000]`，`tud_mounted()` 即返回。本次只补此前 `NOT RUN` 的四项真机数据。

- 镜像：`go run ./cmd/tos build -target rpi-pico-smp`，`build/tinyos-rpi-pico-smp.uf2`
  （2 277 376 B），人工按住 BOOTSEL 写入 `F:\`。
- 端口：板载 CDC `COM17`（VID/PID 2e8a:000a，序列号仍是 `0001`）、
  UART0 = `COM19`（CH343）。
- 计时工具：`scripts/rp2350/cold_watch.py`（本轮补上 RP2040 的
  `[rp2040] boot clk=` banner 识别），连续抓 `[rp2040] boot clk=` →
  `[usb] init done` → `TinyOS shell` → `tos> ` → CDC 节点出现的时刻。
  **口径**：从固件 banner 起算（ROM/上电到 banner 的几毫秒无法从 UART 侧打点），
  不是墙上时钟的"手按下去那一秒"。

## 数据

### 普通 PC 口（直接插 PC USB）

`build/rp2040-pc-cold2.log`：8 次精确计时。

| # | banner→usb init / CDC |
|---|---|
| 1–8 | 0.58 / 0.57 / 0.52 / 0.57 / 0.54 / 0.56 / 0.57 / 0.56 s |

范围 **0.52–0.58 s**，提示符与 `usb init done` 同一时刻，CDC 最多晚 0.01 s。
另有一轮 8 次（`build/rp2040-pc-cold.log`）只记到提示符与 CDC，同样无 trap；
两轮合计 16 次 PC 口冷启动。

### USB hub

`build/rp2040-hub-cold.log`：**5/5**，0.46 / 0.38 / 0.37 / 0.45 / 0.36 s
（范围 **0.36–0.47 s**），CDC 每次在 0.01 s 内出现。

### 无主机（充电头供电，板上 USB 不接 PC）

`build/rp2040-nohost-cold.log`：**5/5**，banner→`tos> ` =
0.37 / 0.45 / 0.35 / 0.45 / 0.45 s（范围 **0.35–0.45 s**）；CDC 始终不存在，
符合预期。pump 跑满窗口也没有明显拖慢启动。

### 回归

- `flash.py --no-flash --smoke -p COM19`：**7/7 PASS**（`echo`、`ls`、`free`、
  `uptime`、`cat /proc/uptime`、`gpio`、`reboot`）。
  同一脚本走 CDC 时会在 `reboot` 那一步撞上 Windows 端口重枚举的
  `PermissionError(13)`——工具在端口消失时还在读，不是固件失败。
- `gpio blink 25 6`：命令返回 `blinking 6 times / done`，用户目视确认 GP25 **闪 6 次**。
- 全部 26 次冷启动（PC 16 + hub 5 + 无主机 5）没有一次 trap 或 CDC 退避。

## 判定

| #31 判据 | 结果 |
|---|---|
| 加有界 pump（与 M33 同形、同折算） | 已在 `670a712` 落地 |
| 普通 PC 口 10 次冷启动 + 上电→CDC 时间 | **PASS**，16 次，0.52–0.58 s（8 次有精确打点） |
| hub / 慢主机 5 次 | **PASS**，5 次，0.36–0.47 s（hub 已验证；未单独模拟更慢主机） |
| 无主机启动时间 | **PASS**，5 次，0.35–0.45 s，pump 未拖慢 |
| `flash.py --smoke` / heartbeat | **PASS**，7/7 + LED 6/6（走 CDC 时端口重枚举是工具限制） |

关闭 #31。pump 没有出现 #29 那种 Hazard3 挂死——再次印证"ARM 两端口可共用形状，
RV32 不行"。RP2040 唯一 USB 序列号仍是 `0001`（不在本 issue 范围），
两块 RP2040 同插仍会撞号。
