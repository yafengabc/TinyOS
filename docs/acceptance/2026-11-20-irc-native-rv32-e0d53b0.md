notes:
- `irc` is a host-side AOT tool in goc32/cmd/irc.  It reuses goc32's RV32
  assembler, ELF linker and LZ4TOS packer.  The board receives only the
  generated ELF/envelope; Go does not run on the target.
- Register mapping: r0..r11 -> s0..s11, r12 -> gp, r13..r15 -> t0..t2.  Each
  RIR function saves ra/s0..s11/gp, loads parameters from the global argbuf,
  and uses the same hidden struct-return destination argument as rirvm.
- Conditional branches are an inverted short branch over a `j` (±1 MiB), so
  RV32's ±4 KiB B-type range cannot break large functions.
- Runtime helpers implement integer/Q16.16 printing, FMUL/FDIV with rirvm's
  exact results, arena strings, bounds traps, and every hardware native
  (GPIO/ADC/PWM/sleep/uptime) through the TinyOS syscall ABI.
- All 17 compilable tests from the tinyos-script suite assemble and link
  natively.  Board results match rirvm:
  fold 14/3; str Hi/65/hello/from-fn/5/4/lit/loc=loX/3/world/world!/xorld!/
  g=Xy/0/-42/name=Xy/n=5; sa3 q=6/p3=16/gs=15/f=3.14/f0=3; nest 3/4/5/7/7/11/
  12/21/20/21/20/21/22/62; sret 3/4/13/14/23/24/3/14/7/8; native 6765;
  fmt 3.14/1.25/0.50/2.00/3/1; hw 22/5/6/1/0 (same as rirvm); many20p 210;
  flow 26/3/4; flow2 5/30/9; switch 105/2/3; copy 10/10/7; mod 2/2/2/2;
  bloop3 1783293664; sieve3 25; ops and floatfold match their host output.
- Native image sizes: raw ELF 2.8–6.7 KiB, LZ4TOS 1.9–2.8 KiB, span 4–8 KiB.
  `fib24` compiles and links but prints nothing by design.
- Final target is an on-board C `irc` (PC-side native compilation already has
  goc32); the Go tool is the reference lowering and runtime.
