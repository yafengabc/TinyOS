## 没跑的

- **Pico 2 RV32 SMP 泵测**：`rpi-pico2-rv32-smp` 的 §19 清单仍待板侧；C3 是单核，
  不能代替它。
- **T4**：没有对应测试项。
- **WiFi 镜像**：需要外部 lib 目录，本轮构建的是不带 WiFi 的 C3。
- **`threadbench` 的 prot=6**：来自 3 个线程栈 malloc 推动 brk，不是切换；兄弟切换
  的 0 次重编程见 `kthreadtest`。
