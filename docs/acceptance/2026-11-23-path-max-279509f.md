## 改了什么

`include/tos.h` 新增 `TOS_PATH_MAX 256`（对应 littlefs 的 255 字节名字上限），
所有路径缓冲改用它：

- 内核 syscall：`open/create/unlink/stat/chdir/readdir/readdir_at`；
- `resolve_path` 的规范化缓冲；
- `struct proc.cwd`；
- 用户态：`ls/msh/sh/edit/lib` 的路径、名字、getcwd 缓冲。

两处配套修复，否则长名字仍然列不出来：

- `enum_name` 从 96 提到 `TOS_PATH_MAX`；根目录快照装不下的名字会置
  `dent_overflow`，让列举走逐次遍历（而不是截断后 stat 失败被 `ls` 跳过）；
  `dent_build()` 现在在 overflow 时返回 -1（之前只在条目数超限时返回）。
- `ls` 的名字缓冲从 64 提到 `TOS_PATH_MAX`。
