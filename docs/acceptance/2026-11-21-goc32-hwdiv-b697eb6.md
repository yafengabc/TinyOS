## 改动

1. `goc32/internal/as/thumb.go`：新增 Thumb-2 的 `udiv`/`sdiv` 与 3 操作数 `mul`
   编码。编码经 `clang -target arm-none-eabi -mcpu=cortex-m33` 逐条核对：

   ```text
   udiv r2,r4,r5 -> fbb4 f2f5      sdiv r3,r1,r6 -> fb91 f3f6
   mul  r2,r4,r5 -> fb04 f205
   ```

   ARMv6-M（RP2040）明确拒绝这些指令。

2. `goc32/internal/native32/arm.go`：`sdiv/udiv` 在 `e.wide`（Thumb-2）时直接发
   `udiv/sdiv`；`srem/urem` 用 `udiv/sdiv` + `mul` + `subs` 展开余数。
   ARMv6-M 仍走原来的 `__aeabi_*` helper（RP2040 无硬件除法）。

3. `goc32/internal/as/as_test.go`：新增编码测试与 Thumb-1 拒绝测试。

这绕开了 #45 描述的递归陷阱：helper 不再被生成的代码调用，所以不需要给
`user/aeabi.c` 补 `-D__ARM_ARCH_EXT_IDIV__`（补了反而会因 goc32 把 `/` 翻成
`bl __aeabi_idivmod` 而无限递归）。
