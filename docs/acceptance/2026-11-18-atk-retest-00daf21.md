## 抓到的回归

按 5566ef5 构建后跑 ATK M33 SMP 验收，`A boot markers [B]..[E]` 失败。查镜像字符串：

```text
kernel-atk-dnr2350am-smp.elf：[A]/[B]/[C]/[D]/[E] 全部 NO
```

即 `TOS_BOOT_TRACE` 被编译成 0。原因：6ca4f18 把开关从环境变量改成配置项后，默认值只写在
`build.Config`（`LoadConfig()`）里；**没有配置文件时 `ApplyConfig()` 不执行**，
`Builder.BootTrace` 保持 Go 的零值 false，于是所有默认构建都把启动标记编译掉了。

`build/build-config.txt` 里正是 `config (none: target defaults)`，所以之前每次 `tos build`
都中招；带 `-config` 的构建（如 `configs/rpi-pico2-quiet.conf`）反而按配置走。

修复：在 Builder 的默认值里也写 `BootTrace: true`（与 `Config` 的默认一致），
两处默认值必须同源，否则"有没有配置文件"会改变镜像内容。
