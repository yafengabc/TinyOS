## 状态机与为什么用 KASSERT

```text
FREE  -> NEW    process_alloc() 认领，exec() 正在构造
NEW   -> LIVE   主线程发布（proc_set_state ST_READY 同一临界区）
NEW   -> FREE   exec() 在发布前失败
LIVE  -> DYING  主线程退出、还有工作线程
LIVE  -> FREE   主线程独自退出
DYING -> FREE   最后一个工作线程收尾
```

非法转移直接 `KASSERT_HALT`：这条路径的错误形态是“进程槽被复用/活进程序被释放”，
不会以崩溃的形式自己暴露，只会过一阵子变成别人的窗口被写坏。

`ps`/`/proc/threads` 跳过 `PROC_NEW`：另一个任务正在 exec 时，ps 不再打印一行
pid=0、名字空的半成品。DYING 仍然显示——用户应该看见进程在收尾。
