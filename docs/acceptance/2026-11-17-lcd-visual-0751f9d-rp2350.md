## 执行的命令与结果

两块板各刷一次当前 `main` 镜像，切 BOOTSEL 用 `flash.py --boot-uart COM14`：

```sh
# ARM（Cortex-M33）
python scripts/rp2350/flash.py --boot-uart COM14 --uf2 build/rp2350smp.uf2 -p COM17 --timeout 90
python scripts/rp2040/heartbeat.py --port COM14 --target rp2350smp        # HEARTBEAT OK 6/6
# 静态：蓝底 + 左上角 LCD OK + 背光
screen backlight on; screen clear blue; screen text 1 1 LCD OK            # ARM 屏正常（目视）
# 多行：screen mirror on + ls /bin
screen mirror on; screen clear black; ls /bin                             # ARM 多行无撕裂（目视）

# RV32（Hazard3）
python scripts/rp2350/flash.py --boot-uart COM14 --uf2 build/rp2350rvsmp.uf2 -p COM17 --timeout 90
python scripts/rp2040/heartbeat.py --port COM14 --target rp2350rvsmp      # HEARTBEAT OK 6/6
screen backlight on; screen clear blue; screen text 1 1 LCD OK            # RV32 屏正常（目视）
screen mirror on; screen clear black; ls /bin                             # RV32 多行无撕裂（目视）
```
