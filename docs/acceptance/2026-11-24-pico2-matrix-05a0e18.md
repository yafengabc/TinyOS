## 与本次修复直接相关的证据

ARM 两镜像的故障转储里，SysTick 仍然高于故障处理器：

```text
shpr1=0x00404040 shpr2=0x40000000 shpr3=0x20e00000
```

`shpr1` 的 `bits[7:0]` 是 0x40（修复前是 0x00）。五个 `prot` 用例（rodata /
heap / stack / null / dev）在两块 ARM 镜像上都打印 MemManage 后回到提示符；
RV32 侧仍是 PMP 语义：heap/stack/dev 触发 `store access fault`
（0x…c0de / 0x…c110 / 0x…c198），rodata/null 按设计存活。两个 SMP 镜像各跑了
`crash`（heartbeat 第 6 项）与 200 轮 dd，没有再出现 ATK 上那种 tick 冻结。
