## 结论：sh 有、msh 没有的命令

| sh 内建 | msh | 处理 |
|---|---|---|
| `cd` `pwd` `rm` `ps` `exit` `source` `run` `nice` `prio` `echo` `true` `false` `sleep` `history` | 有 | 不动 |
| `help` | **无** | 本次移到 `/bin/tools`，两个 shell 共用 |
| `incr` | **无** | 必须留在 shell：它改的是调用者的变量，子进程改不到父进程 |
| `if` `while` `else` `fi` `done` `break` | 无 | 脚本语法，不是命令，没有可执行的东西 |
| `reboot` | 无内建 | `/bin/reboot` 本来就在，msh 直接能跑（`ls -l /bin/reboot` 475 B） |

所以真正“msh 下缺失”的只有 `help`；`incr` 不是“没搬”，是搬不走——要让它
在 msh 里可用只能加进 msh 的内建，而 rp2040 上 msh 只差 60 B 就到 8 KiB 镜像
上限（再涨就变 12 KiB span、32 KiB 窗口，`TOS_WINDOW(16 KiB)` 直接拒绝）。

## 实现

- `user/tools/help.c`：`applet_help`，文本按“两个 shell 共有的内建 / tools
  applet / `/bin` 程序 / 文件与管道 / 仅 sh 的脚本语法”重写；applet 清单用
  `tools/applets.h` 的 X-macro 打印，加 applet 不会留下过期的帮助文本；
- `user/sh.c`：删掉 `cmd_help`（65 行）和它的 `run_command()` 分支，`help`
  于是走普通的程序路径（`spawn()` 失败后重试 `/bin/tools`）；
- `user/msh/msh.c`：只改注释，说明 `help` 在 applet 里、`incr` 为什么搬不走；
  msh 代码和窗口大小都没变；
- `docs/SHELL-GUIDE.md`：示例输出换成实跑抓的新文本，名字解析补上第 3 步
  （cwd → `/bin` → `/bin/tools`，前两步在内核，第 3 步在 shell）。

## 实测（C3，默认镜像，新刷入未跑 accept 时）

| | 改前（`ff8707e`） | 改后（`6fe6653`） |
|---|---|---|
| `df` used | 323,584 B | **319,488 B**（少 1 个 4 KiB block） |
| `/bin/tools`（ELF） | 10,902 B | 13,558 B（+2,656 B，帮助文本） |
| `/bin/sh`（ELF） | — | 9,398 B（少了 2.6 KiB 字符串） |
| `/bin/msh`（板上） | 4,516 B | 4,516 B（不变） |
| msh 窗口（rp2040） | 16 KiB | 16 KiB（`rpi-pico` 构建通过） |

`tools` 涨的 2.6 KiB 落在它原有的最后一个 block 里，`sh` 掉的 2.6 KiB 跨过
block 边界，所以 `df` 净少一个 block。

## 窗口代价（`span + 4 KiB stack + 4 KiB guard`，4 KiB grain 向上取整）

| 目标 | `tools` span / 窗口 | `sh` span / 窗口 | `msh` |
|---|---|---|---|
| rv32（C3、rp2350rv、pico2-rv32、QEMU rv32） | 20 KiB / 28 KiB → **24 KiB / 32 KiB** | 20 KiB / 28 KiB → 16 KiB / 24 KiB | 8 KiB / 16 KiB（不变） |
| ARM（rp2040、rp2350、pico2、QEMU arm） | 24 KiB / 32 KiB → **28 KiB / 36 KiB** | 28 KiB / 36 KiB → 24 KiB / 32 KiB | 8 KiB / 16 KiB（不变） |

也就是把 sh 的一个 grain 转给了 tools：`help` 运行时是 shell + applet 两个
窗口（rv32 24+32=56 KiB，ARM 32+36=68 KiB），比原来在 shell 内打印（单窗口
28/36 KiB）多占一个 applet 窗口。只在 `help` 执行期间存在；rp2040 的 264 KiB
用户区仍容得下 shell 加两个 applet（36+36+36=108 KiB）。

> 后续：[`371b63c`](2026-11-28-tools-opt-371b63c.md) 让 `tools` 用 `-Oz` 编译，
> ARM 的 `tools` 从 36 KiB 回到 32 KiB（rv32 不变），所以现在的组合是
> rv32 24+32、ARM 32+32。
