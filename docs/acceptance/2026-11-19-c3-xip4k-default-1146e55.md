What changed
------------
- board/esp32c3-generic/board.conf now sets xip_flash_base = 0x4000 and
  xip_map_base = 0.  The 64 KiB MMU page is still mapped at 0x42000000; the
  code starts inside it at 0x42004000.  The ROM-loadable boot image ends
  around 0x1A00, so ~9.5 KiB remains before the code (the build fails if it
  grows past the offset).
- No per-config xip overrides are needed any more.  The old xip2k configs
  are gone; configs/esp32c3-wifi-ble.conf is the WiFi/net -Oz variant kept
  for BLE bring-up.
- The filesystem offset is unchanged at 0x80000; only the kernel end moved.
