## 顺手修的：soak 假设镜像里有 `py`

第一次跑 soak 直接报了 3 个 `exec: '/bin/py' not found`（第 0/8/16 轮）。`py` 在
`defaultUserExclude` 里，任何镜像都不带，所以这不是内核错误，是脚本的旧假设——
和 emutest 里那三条 python 检查同源。`workload()` 现在先看 `ls /bin`，没有 `py`
就不排这条命令（`has_py`），并在日志里写明 `py=False`。

## 没跑的

- **M33 / RP2040 / RP2350 真机**：本机没有这些板子（只有 C3 在 COM4），
  按 `docs/OPEN-ITEMS.md` §22 的清单由板侧执行。
- **更长的浸泡**：30 分钟已经是 T4 的要求；更久（比如 2 小时）不在本轮范围。
- **`kthreadtest`**：C3 镜像没有 `kthreads` 特性（`board/esp32c3-generic/board.conf`
  的 features 只有 pwm/spi/i2c/rir），该用例在 RP2350/RP2040 上跑。
