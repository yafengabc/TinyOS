notes:
- map_page() records page_tag[slot] only after a successful read, so a failed
  read cannot be mistaken for a cached page.
- `pc` is bounds-checked against nir only on a page miss: a bad target stops
  with "rvm: pc out of range" instead of reading past the image.
- The file descriptor stays open for the whole run; pages are immutable, so
  they survive across reps.
- Load-time checks now include the file size, so a truncated header still
  fails before the first instruction executes.
