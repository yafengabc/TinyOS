## 没跑的

- `deep 6` 的"通过"：C3 默认 8 KiB 栈无法再翻倍，内核按设计杀任务。这是已知行为，
  不是回归；要覆盖更深递归需程序声明 `TOS_STACK()`。
- **goc32**：当前 HEAD 上 `cd goc32 && go run . ../user/hello.c` 失败
  （`__builtin_offsetof`），已作为 A-2 的回归记在 issue #2，等修复后补测。
