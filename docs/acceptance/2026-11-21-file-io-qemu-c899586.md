- IR: new opcode NATIVEC id, dst.  Arguments are written by ARG into
  data_argbuf (the buffer normal calls already use); the native reads them
  there.  Existing NATIVE/NATIVER encodings are unchanged, so old images and
  the run() native keep working.
- csc: native ids 12..17 (open/create/read/write/close/unlink).  Paths and the
  read/write buffer are checked to be strings (arena offsets), not ints.
- rvm: board builds call open/read/write/close/unlink directly; the host build
  returns -1 (no TinyOS filesystem), so file1 is target-only.
- rcc: RV32 uses SYS_OPEN(4)/SYS_CREATE(11)/SYS_READ(2)/SYS_WRITE(1)/
  SYS_CLOSE(5)/SYS_UNLINK(31) with the arena base added to the offset;
  Thumb-2 does the same with svc.

  byte count and the buffer.  Output on both targets: 1, 5, 0, 5, hello, 0, 0.
