## 行为

- `ls`：名字两空格分隔，78 列换行；目录带尾随 `/`。
- `ls -l`：原来的长格式，一行一个（类型、名字、大小 / `<dir>` / `<dev>`）。
- `ls <file>`：只打印名字；`ls -l <file>`：长格式。
- 未知选项报错，不会被当成路径。
